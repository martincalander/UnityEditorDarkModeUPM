# Changelog

## [Unreleased]

## [1.1.1] - 2026-08-30

- Changed the package ID from `com.0x7c13.darkmode` to
  `com.martincalander.editordarkmode`.
- Renamed the Package Manager entry to Editor Dark Mode.
- Listed Martin Calander as the package contact. The extension itself is Jiaqi
  Liu's work.
- Added license notices for ReaperThemeHackDll and inipp.
- Added signed UPM release packaging, a checksummed Unity bootstrap installer,
  and OpenUPM release-asset publication.
- Documented bootstrap, OpenUPM, signed tarball, pinned Git URL, and local-folder
  installation methods.
- Added explicit native DLL provenance, checksum, signature limitations,
  supported Windows versions, and restart guidance.
- Moved package artwork into the Unity-hidden `Documentation~` directory and
  added the OpenUPM cover image.

## [1.1.0] - 2026-03-05

- Packaged Jiaqi Liu's UnityEditor-DarkMode v1.1 release for UPM.
- Added the README, changelog and MIT license.
- Included Jiaqi Liu's unmodified v1.1 DLL and its default config.
